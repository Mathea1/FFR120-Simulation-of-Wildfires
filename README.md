# Simulation of Wildfires
Partaking individuals in the project include: Alfons Otterspeer 

The study investigates the relationship between forest size and the eventual wildfire damage with additional parameters being present. With the worlds ongoing pollution crisis the average temperature is steadily increasing resulting in a growing number of forest fires around the world. By simulating the scenarios with varyious surroundings different strategies to stop/prevent wildfires may hopefully be found.
